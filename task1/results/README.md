All Task 1 outputs are written here (or to `$ATML_ARTIFACTS_ROOT` on Kaggle).

After Kaggle runs finish, pull outputs with:

```bash
kaggle kernels output mtayyabtahir/atml-pa3-t1-train-full-ft -p ./kaggle_pulls/train-full-ft
```

Then merge into this tree before compiling the report.
